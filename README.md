A responsive corporate website for **BAWABAT ALWAJIHAT COMPANY (BAC)**, a premium provider of aluminum windows, doors, and façade solutions based in Al Kharj, Saudi Arabia.


## 🛠️ Tech Stack
- **HTML5 & CSS3** — semantic markup and custom styling
- **Bootstrap 5.3** — responsive grid and components
- **Font Awesome 6.7** — iconography
- **WOW.js + Animate.css** — scroll-triggered animations
- **Lucide Icons** — lightweight SVG icon set
- **Vanilla JavaScript** — hero slider, sticky navbar, number counter, loading screen

## ✨ Features
- Animated loading screen with brand identity
- Sticky navbar with smooth scroll navigation
- Hero image slider
- Scroll-reveal animations throughout
- Animated statistics counter section
- Services showcase with hover effects
- Marquee CTA banner
- Contact form with validation
- Fully responsive across all screen sizes
